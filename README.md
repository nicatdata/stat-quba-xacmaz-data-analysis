# Quba-Xaçmaz Regional Statistical Data Analysis (2015-2024)

This repository contains an end-to-end data analytics project on the official statistical dataset of the Quba-Xaçmaz economic region in Azerbaijan.

## 📂 Repository Contents
- **`008 (4).xlsx`**: Raw Excel dataset from the State Statistical Committee.
- **`quba_xacmaz_clean_data (4).csv`**: Cleaned and transformed dataset in tidy (long) format.
- **`Untitled3 (1).ipynb`**: Jupyter Notebook containing Python parsing, cleaning, and visualization scripts.
- **`Quba-Xaçmaz Regional Statistical Report.pdf`**: Comprehensive 4-page analytical report featuring multi-chart dashboards, statistical tables, and demographic insights.

## 🛠️ Tools & Technologies
- **Python** (Pandas, NumPy, Matplotlib, Seaborn)
- **Data Preprocessing** (Melting, UTF-8 Encoding, Cleaning)
- **Jupyter Notebook / Google Colab**
- **Git & GitHub**
